Deploy Keamanan RABIT

5 langkah, sekitar 10 menit. Ikuti berurutan — login akan gagal sampai langkah 5 selesai.

1

Backup project Apps Script

Buka script.google.com, pilih project yang menangani RAB, lalu:

  1. Menu File
  2. Make a copy

Ini titik balik kalau ada masalah. Jangan dilewati.

2

Set secret keamanan Wajib

Secret ini dibuat sekali di sini. Jangan taruh di kode atau di chat.

63a69b5f92b46b05d0b690b7fde52a5a45bf1bd8d06062ad064af729b7f58503

Tempel ke: Project Settings (ikon gerigi) → Script properties → Add script property

  1. Property: RABIT_SECRET
  2. Value: string di atas
Kalau secret ini bocor, siapa pun bisa membuat token palsu. Simpan hanya di Script properties.
3

Buat hash password

Jalankan di terminal (folder repo):

node apps-script/siapkan-user.js

Skrip akan menanyakan username, nama, role, dan password. Di akhir ia mencetak blok var USERS = { ... } yang siap ditempel. Password tidak disimpan ke disk.

Password minimal 10 karakter. Skrip menolak yang lebih pendek.
4

Tempel kode ke Apps Script Hati-hati

Isi apps-script/Code.gs dari repo. Ambil isinya dengan:

cat apps-script/Code.gs

Lalu di editor Apps Script:

  1. Ganti isi Code.gs dengan isi tadi
  2. Ganti blok var USERS = {...} dengan hasil langkah 3
  3. Simpan
Jangan menimpa fungsi lama Anda. Kalau project punya fungsi lain (misalnya doGet untuk data aktivasi Berita Acara), gabungkan: pertahankan fungsi lama, tapi tambahkan pengecekan verifikasiToken() di awal setiap doGet/doPost.
5

Deploy ulang & verifikasi

Di Apps Script: Deploy → Manage deployments → ikon pensil → Version: New version → Deploy.

  1. Execute as: Me
  2. Who has access: Anyone
Akses harus Anyone — browser memanggil tanpa login Google. Keamanan datang dari token, bukan dari pembatasan akses.

Verifikasi di terminal:

curl -sL "https://script.google.com/macros/s/AKfycbz3eaTzjPnmwCUHwqVOxpO_rRZj4M7Qfpr7w_0p_RgV_GxtRwNfaOYt-jySVnpkc4vEUw/exec"

Harus membalas: {"status":"error","message":"Unauthorized"}

Kalau masih membalas daftar RAB, token belum diwajibkan — ulangi langkah 4 dan 5.
6

Uji login

Buka aplikasi, login dengan akun baru. Bila berhasil masuk dashboard, selesai.

Bagikan password ke pengguna lewat jalur aman (WhatsApp/email langsung, bukan grup).

Akun lama admin/admin sudah dihapus dari kode dan tidak akan berfungsi lagi.

Kalau macet

Error RABIT_SECRET belum diset → langkah 2 belum selesai.
Login selalu "Username atau password salah" → hash di USERS belum cocok; ulangi langkah 3 lalu 4.
Endpoint masih membalas data → deployment belum versi baru.
